TEXTILECORE - TEZKOR BOSHLASH VA QO'LLANMA (Windows)

Jonli sayt:        https://textile-factory-ai-six.vercel.app
Mijozlar katalogi: https://textile-factory-ai-six.vercel.app/store
Telegram bot:      @TextileCoreZaraBot

----------------------------------------------------
1. KOMPYUTERDA ISHGA TUSHIRISH
----------------------------------------------------
Kerak: Python 3.11+ va Node.js 20+ o'rnatilgan bo'lsin.

Birinchi marta o'rnatish (PowerShell, loyiha papkasida):

   cd backend
   python -m venv venv
   venv\Scripts\pip install -r requirements.txt
   copy .env.example .env

   So'ng backend\.env faylini oching va yozing:
     DATABASE_URL=<Supabase "Session pooler" manzili>
     SUPABASE_URL / SUPABASE_SECRET_KEY                  (rasmlar va bulutdagi zaxira uchun)
     JWT_SECRET_KEY=<istalgan uzun tasodifiy matn, kamida 32 belgi>
     CORS_ORIGINS=http://localhost:5180
   Internetsiz lokal sinov uchun: DATABASE_URL=sqlite:///./textile_dev.db

   cd ..\frontend
   npm install

Ishga tushirish:   ishga-tushirish.bat   (orqa fonda; brauzer o'zi ochiladi: http://localhost:5180)
   yoki terminalda:   npm run dev        (loyiha papkasida; oyna yopilsa to'xtaydi)
To'xtatish:        toxtatish.bat
Avtostart:         avtostart-yoqish.bat  (o'chirish: avtostart-ochirish.bat)
Muammo bo'lsa:     logs\ papkasidagi jurnallarga qarang.

----------------------------------------------------
2. ZAXIRA NUSXA
----------------------------------------------------
- Har kuni 19:00 da bazaning to'liq nusxasi Supabase'dagi yopiq "backups" bucket'iga
  avtomatik yuklanadi (oxirgi 14 kuni saqlanadi). Supabase -> Storage -> backups.
- Kompyuterda: zaxira-olish.bat  (backend\backups\*.db, oxirgi 14 tasi saqlanadi).
- Tiklash: .db.gz faylni yuklab oching (7-Zip), keyin backend papkasida:
     venv\Scripts\python -m scripts.migrate_to_supabase --source sqlite:///./backups/<fayl>.db --replace

----------------------------------------------------
3. ASOSIY BO'LIMLAR
----------------------------------------------------
Dashboard           Asosiy ko'rsatkichlar, shu oy foyda, to'lanmagan ish haqi, mijoz savollari.
Hisobotlar          Ishlab chiqarish, brak, KPI, savdo, tannarx, ombor, yetkazib beruvchilar (Excel).
Foyda va xarajatlar Ijara, kommunal, soliq va h.k. kiritiladi; oylik sof foyda avtomatik hisoblanadi.
Buyurtmalar         Katalog va qo'lda kiritilgan buyurtmalar, holati, jo'natmalar.
Mijoz savollari     Katalogdagi "Savol berish" orqali kelgan savollar; qo'ng'iroq qilib javob bering.
Ish buyurtmalari    Kesish -> Tikuv -> Pardoz -> Sifat -> Qadoqlash; QR skaner.
Xodimlar            Xodim kartochkasi, stavka (oylik / soatbay / ishbay).
                    Telegram belgisi -> xodimga shaxsiy QR/havola (bot orqali o'z natijasini ko'radi).
Xodim qo'shish      Alohida sahifa: qo'lda kiritish yoki Telegram taklif havolasi/QR.
                    Xodim havolani ochib raqamini yuboradi -> so'rov shu sahifaga va zavod chatiga keladi
                    -> bo'limni tanlab "Qabul qilish" (xodim botga avtomatik ulanadi).
Davomat             Kelish-ketish, kechikish, javob so'rovlari.
Ish haqi            Oy bo'yicha avtomatik hisob; bonus, jarima, avans; "To'lash"; hisob varaqasi.
Ombor               Materiallar, kirim-chiqim, ombor joylari, tayyor mahsulot.
Omborchi rejimi     Telefonda: QR skanerlab kirim / chiqim / ko'chirish / sanash (Android Chrome).
QR yorliqlar        Materiallar va Ombor joylari sahifalarida -> chop etib javonga yopishtiring.
Ombor hisobotlari   Oylik aylanma, qiymat bo'yicha, harakatsiz qoldiqlar.
Sozlamalar          Profil, parol, til (UZ/RU/EN), zavod nomi, Telegram, tannarx sozlamalari.

----------------------------------------------------
4. TELEGRAM BOT
----------------------------------------------------
Zavod egasi:  Sozlamalar -> Telegram -> "Botni ochish" -> Start. Keyin yangi buyurtma,
              material tugashi, mashina buzilishi, javob so'rovlari va kunlik hisobot keladi.
              Yangi buyurtma xabarida "Tasdiqlash" / "Bekor qilish" tugmalari bor.
Mijoz:        /start -> "Do'konni ochish" (katalog Telegram ichida). Buyurtma holati botga keladi.
              Zavodning do'kon havolasi: Sozlamalar -> Telegram -> "Mijozlar uchun do'kon havolasi".
Xodim:        Xodimlar -> Telegram belgisi -> QR. /me - bugungi va oylik natija, ish haqi.
              Yangi xodim: Xodim qo'shish -> Telegram taklif havolasi -> "Raqamni yuborish";
              zavod chatida bo'lim tugmasini bosib qabul qilinadi yoki "Rad etish".
              Javob so'rash: xodim /leave (yoki "Javob so'rash" tugmasi) -> sabab turi -> kunlar ->
              sababini yozadi. Rahbar zavod chatida "Tasdiqlash"/"Rad etish" bosadi (yoki saytda
              Davomat -> Javob so'rovlari); natija xodimga botda keladi.
Buyruqlar:    /start  /shop  /orders  /me  /leave  /help
